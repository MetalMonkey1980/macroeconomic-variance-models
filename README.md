# Macroeconomic Variance Models

This repository provides Python-based framework tools to compute, analyze, and visualize variance and volatility in macroeconomic time-series data (e.g., GDP growth, inflation tracking, and interest rate shocks).

## Features
* **Data Processing**: Automatic cleaning of macroeconomic datasets.
* **Variance Modeling**: Rolling window variance and standard deviation calculations.
* **Statistical Indicators**: Z-score standardization and outlier detection.

## Project Structure
* `data_analyzer.py` — The core Python executable script for statistical modeling.
* `data/` — (Optional) Directory containing sample economic CSV inputs.

## Quick Start
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Install dependencies:
   ```bash
   pip install pandas numpy matplotlib
   ```
3. Run the analyzer:
   ```bash
   python data_analyzer.py
   ```
